INTERMEDIATE VALUE THEOREM

Continuity, completeness, and the bisection method

Calculus is the study of continuous functions. Knowing that a function is continuous allows us to make use of a wealth of properties that range from the obvious to the subtle. Perhaps the most intuitive theorem of calculus is the intermediate value theorem (IVT):

Theorem 4 (Intermediate value theorem). If y = f ( x ) y=f(x) is a function that is defined and continuous on a closed interval [ a , b ] [a,b] , then this function assumes every value between f ( a ) f(a) and f ( b ) f(b) . In other words, if L L is a real number such that f ( a ) < L < f ( b ) f(a)<L<f(b) or f ( a ) > L > f ( b ) f(a)>L>f(b) , then there exists at least one point c c in ( a , b ) (a,b) such that f ( c ) = L f(c)=L .

Remark 1. While this theorem might seem obvious, it is actually a defining property of the real numbers, as compared to other sets of numbers such as the rational numbers. Such defining properties are called completeness axioms, and many theorems of calculus may be taken as a single completeness axiom for the real numbers. Such an axiom is not proven, as opposed to a theorem; it must be taken as an assumption. The IVT can either be taken as a completeness axiom, or be proved from another completeness axiom. For interested readers with an understanding of proofs, see this article.

Bisection method

The reason why the IVT is useful is the case where L = 0 L=0 . It says that any function f f has a real-valued root whenever there exists a closed interval [ a , b ] [a,b] where f ( a ) f(a) and f ( b ) f(b) have opposite signs.

The bisection method goes as follows. We first choose X X and Y Y in the domain of f f . If f f changes sign on the interval [ a , b ] [a,b] , or equivalently if f ( a ) f ( b ) < 0 f(a)f(b)<0 , then we bisect the interval by computing the midpoint c = ( a + b ) / 2 c=(a+b)/2 . This is our first guess of the root of f f .

If f ( c ) = 0 f(c)=0 , then we are done. (You’d have to get seriously lucky for this to occur!) If not, f f either changes sign in ( a , c ) (a,c) or in ( c , b ) (c,b) . The interval containing the sign change contains the root in the same place, and once the proper interval is determined, it is bisected as we did earlier. This process of bisection can be repeated until a point of bisection is reached that approximates the root of f f to a desired level of accuracy (e.g. correct to 4 decimal places).

This method works best when we have little information about the function f ( x ) f(x) . However, convergence depends on the initial choice of interval [ a , b ] [a,b] , and convergence to the root may be rather slow.
