Definition of a function

In high school math, we have an intuitive understanding of a function as a curve which represents an association between an input variable x x and an output variable y y . In this section, we will refine this understanding by precisely defining what a function is. Functions are much more than curves on a grid, and opening ourselves up to a more precise and general definition is the first step to familiarize ourselves with the variety of definitions and theorems we encounter in calculus.

We use the definition of a function given in [1]:

Definition. Given two sets X X and Y Y , a function from X X to Y Y is a rule or mapping that takes each element of X X and associates with it a single element of Y Y . In this case, we write f : X → Y f:X \to Y .

X X is said to be the domain of the function f f , while Y Y is said to be its codomain. All elements of Y Y do not necessarily occur as outputs of f f , and the ones that do form a subset of Y Y known as the range of f f .

You are already familiar with functions: linear equations y = m x + b y=mx+b and quadratic equations y = a x 2 + b x + c y=ax^2+bx+c are examples of functions of the variable x x , where m , a , b , c m,a,b,c are constants. In this case, we write y = f ( x ) y=f(x) , where x x represents elements of the domain and y y represents elements of the range. Given any x x in the domain, f ( x ) f(x) produces one and only one value.

This leads us to the familiar notion of the vertical line test: at any point on the graph of the function, it must intersect a vertical line exactly once. A graph failing the vertical line test is equivalent to the existence of an element x x of the domain that is associated to more than one element of the codomain. Such a graph would not represent a proper function, because we need each element of the domain to output an single value to the range under f f .
