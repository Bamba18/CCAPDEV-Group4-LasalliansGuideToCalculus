Approximation methods

Another application of the derivative is its use in approximating roots of continuous functions. We already saw the bisection method (see IVT page), but we noted that its convergence was rather slow. It turns out that, with the derivative, we can approximate roots much faster.

Newton’s method

Secant method

Mean value theorem

Along with the intermediate and extreme value theorems, we have a third theorem which can be used to show that these methods do indeed converge to a root.

Theorem 3 (Mean value theorem). Let f ( x ) f(x) be a function continuous on the interval [ a , b ] [a,b] and differentiable on the interval ( a , b ) (a,b) . Then there exists at least one point c c in the open interval ( a , b ) (a,b) such that f ′ ( c ) = f ( b ) − f ( a ) b − a . f'(c) = \frac{f(b)-f(a)}{b-a}.

While, like the other two, this seems intuitively obvious, it allows us to say that the derivatives at any point in the interval we choose actually exist, and hence Newton’s method (and thus the secant method) converge to a true root of a function.

Remark 3. Just like the intermediate and extreme value theorems, this is also a completeness axiom. See the IVT page for details.
