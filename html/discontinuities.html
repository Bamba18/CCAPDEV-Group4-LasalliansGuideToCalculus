Types of discontinuities

The functions we’ve usually encountered, such as linear equations, quadratic equations, and polynomials of any degree n n , obey useful properties: they are defined for all real numbers, and they are continuous everywhere. Intuitively, we say a function is continuous if we can draw its graph with a pencil without ever lifting it. We will make this precise soon, but (by taking the contrapositive statement) we can intuitively understand discontinuities as points on a function’s graph where you would need to lift the pencil. There are three kinds of discontinuities, and each of them require in different ways.

Removable discontinuity

Consider the function f ( x ) = 2 x 2 + x x , f(x)=\frac{2x^2+x}{x}

Click and drag along the graph, and notice that the y-values get closer and closer to 1 from both sides as the x-values approach 0. But at x = 0 x=0 itself, we get ( 0 , undefined ) (0, \text{undefined}) and this is because we end up dividing by 0, and remember that any number divided by 0 gives an undefined value. So even though the function seems to “close in” on the point x = 0 x=0 , f ( x ) f(x) itself is not defined at x = 0 x=0 , and we can say that its domain is ℝ ∖ { 0 } \mathbb{R} \backslash \{0\} (all real numbers except 0). But we can easily factor the numerator of f f and get f ( x ) = 2 x 2 + x x = x ( 2 x + 1 ) x = 2 x + 1 f(x)=\frac{2x^2+x}{x}=\frac{\cancel{x}(2x+1)}{\cancel{x}}=2x+1. Now we can evaluate this function at x = 0 x=0 ; we easily get f ( 0 ) = 2 ( 0 ) + 1 = 1 f(0)=2(0)+1=1 . But originally f f was not defined for this value! What we have just done is evaluate the limit of f ( x ) f(x) as x x “approaches” 0 (we will soon elaborate what we precisely mean by “approaching”).

Observe the graph of f ( x ) f(x) . It looks exactly like how one would graph the line y = 2 x + 1 y=2x+1 , but with a at x = 0 x=0 , where the function is not defined. This hole is said to be a removable discontinuity. When a function has a removable discontinuity, the limit can be evaluated at that point. Hence we write lim x → 0 f ( x ) = lim x → 0 2 x 2 + x x = lim x → 0 ( 2 x + 1 ) = 2 ( 0 ) + 1 = 1 . \lim_{x \to 0} f(x) = \lim_{x \to 0} \frac{2x^2+x}{x} = \lim_{x \to 0}(2x+1) = 2(0)+1 = 1. In general, if the limit exists at a point x = a x=a even though f ( a ) f(a) is undefined, then lim ⁡ x → a f ( x ) = f ( a ) \lim_{x \to a} f(x) = f(a) .

Going back to the idea of graphs drawn with pencils, we can represent a removable discontinuity at a point by erasing a part of the graph around said point. Obviously, since a point is arbitrarily small, such an erasure is not to scale.

Jump discontinuity

Functions may be defined by different equations on different intervals; this is not inconsistent with our definition of a function as long as the equations are functions themselves. We call such functions piecewise-defined or simply piecewise.

Consider the following piecewise function, constant across two different intervals:

f ( x ) = { 0 , x < 0 ; 1 , x > 0 . f(x) = \begin{cases} 0, & x<0; \\ 1, & x>0 \end{cases}

This function occurs frequently in engineering and is known as the Heaviside function. Observe that if we approach 0 from the left (i.e. for negative values of x x ), we have f ( 0 ) = 0 f(0)=0 , and if we approach 0 from the right (i.e. for positive values of x x ), we have f ( 0 ) = 1 f(0)=1 instead! We write this as lim x → 0 − f ( x ) = 0 , lim x → 0 + f ( x ) = 1 , \lim_{x \to 0^-} f(x)=0, \qquad \lim_{x \to 0^+} f(x)=1, and we say that these are the left-hand and right-hand limits of f ( x ) f(x) at x = 0 x=0 . (The fact that a limit can be approached from both directions is not something we mentioned in the previous example, and we now show it here.) Since these limits both exist but aren’t equal, f ( x ) f(x) is said to have a jump discontinuity at x = 0 x=0 . A proper limit as we have exhibited previously cannot exist at a jump discontinuity, because the limits from both sides need to be equal, and this is true even if the domain of the function is all of ℝ \mathbb{R} .

When drawing a jump discontinuity, we lift the pencil at the point of the jump discontinuity and then move our hand vertically, either upwards or downwards, from where we continue drawing the function. We mark jump discontinuities by drawing small holes to indicate that the function is not defined there.

Essential discontinuity

Now consider the function f ( x ) = 1 ( x − 1 ) 2 . f(x)=\frac{1}{(x-1)^2}.

Easily we see that the domain of f f is ℝ ∖ { 1 } \mathbb{R} \backslash \{1\} . Is it possible to evaluate the limit of this function at x = 1 x=1 ? Unlike with our example for the removable discontinuity, there isn’t any way to get x x out of the denominator. Thus f f has an essential discontinuity at x = 1 x=1 . Limits cannot be evaluated at essential discontinuities.

Hover your mouse over the graph and scroll down to zoom out the graph, and notice that, no matter how far you zoom out, f ( x ) f(x) blows up towards + ∞ +\infty for values of x x approaching 1, both from the right and the left. We thus write lim x → 1 − f ( x ) = + ∞ , lim x → 1 + f ( x ) = + ∞ . \lim_{x \to 1^-} f(x) = +\infty, \qquad \lim_{x \to 1^+} f(x) = +\infty. However, since ∞ \infty is not a number, we cannot say that the left-hand and right-hand limits are equal. They just both grow without bound.

Observe from the graph of f f that the dotted vertical line at x = 1 x=1 is a vertical asymptote, and this is a characteristic of any essential discontinuity at any point. When we draw a function with an essential singularity, the graph of the function splits across the vertical asymptote, approaching but never touching it.
