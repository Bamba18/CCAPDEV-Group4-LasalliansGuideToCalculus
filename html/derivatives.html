The derivative and differentiable functions

In class, you may be familiar with the notion of the derivative of a function at a point as the line that is tangent to the curve of the function at that point. But how do we properly define the tangent line? Thankfully, since we have already tackled the notion of a limit, we have the tools to answer this question.

Most functions can be differentiated more than once. We define the second-order and third-order derivatives to be f ″ ( x ) = f ′ ( f ′ ( x ) ) , f ‴ ( x ) = f ′ ( f ″ ( x ) ) ; f''(x) = f'(f'(x)), \qquad f'''(x) = f'(f''(x)); and in general the n n th-order derivative is denoted f ( n ) ( x ) f^{(n)}(x) . (We stop with apostrophes and start writing numbers after the third-order derivative.) Functions that are differentiable an infinite amount of times in their domain are said to be C ∞ C^{\infty} -functions, and this class includes your usual functions: polynomials, rational functions, trig functions, the exponential e x e^x (obviously), logarithms like ln ⁡ x \ln x , etc.

Observe from both equivalent definitions of the derivative that they require f ( x ) f(x) to be defined and continuous at x = a x=a . While this might seem obvious, what may not be is the fact that a function that is continuous at a point is not necessarily differentiable there.

Example 1. Let f ( x ) = | x | f(x)=|x| . Since the slope to the left of x = 0 x=0 is − 1 -1 and the slope to the right of x = 0 x=0 is 1, the left-hand and right-hand limits in the definition of the derivatives are not equal. Thus the derivative of | x | |x| does not exist at x = 0 x=0 .

Fortunately, in the words of famous math writer Ian Stewart, we avoid this problem by ignoring it. In calculus class, we only really consider C ∞ C^{\infty} -functions for simplicity, and ignore such examples as above, which are said to be pathological. (This example is quite tame: there exist functions that are continuous everywhere but differentiable nowhere. This is a truly pathological function.)

Remark. It is due to these pathological functions that mathematicians felt the need to properly and rigorously formalize the entire field of calculus, leading to the epsilon-delta definition of a limit we tackled previously. This lead to the establishment of real analysis, which is something math majors will encounter later. While the rest of you don’t need to worry about this for your grades, the theory is still beautiful and worth learning about.

Applications of the derivative

The value of the slope of a tangent line gives us vital information about the behavior of the function around the point of tangency. First, it tells us where the function is increasing or decreasing. Increasing/decreasing behavior is easy to see visually, so we can formalize this notion by saying that a function is increasing on an interval if, given x 1 , x 2 x_1,x_2 in this interval, x 1 < x 2 x_1<x_2 implies f ( x 1 ) < f ( x 2 ) f(x_1)<f(x_2) . Analogously, a function is decreasing if x 1 < x 2 x_1<x_2 implies f ( x 1 ) > f ( x 2 ) f(x_1)>f(x_2) .


The function g ( x ) =- x^2 + 2 g(x) = -x^2 + 2 above is increasing on ( -∞ , 0 ) (-∞,0), and decreasing on ( 0 , ∞ ) (0,∞).

Let f f be a C ∞ C^{\infty} -function. If f f is increasing on an interval, then x 1 < x 2 x_1<x_2 implies f ( x 1 ) < f ( x 2 ) f(x_1)<f(x_2) for any x 1 , x 2 x_1,x_2 in that interval. We can restate this as saying that ( x 2 − x 1 ) > 0 (x_2-x_1)>0 implies f ( x 2 ) − f ( x 1 ) > 0 f(x_2)-f(x_1)>0 . Then since the slope is given by m = f ( x 2 ) − f ( x 1 ) x 2 − x 1 m=\frac{f(x_2)-f(x_1)}{x_2-x_1} as we wrote earlier, since both the numerator and denominator are positive, the slope m m must be positive. When f f is decreasing, we have f ( x 2 ) − f ( x 1 ) < 0 f(x_2)-f(x_1)<0 , hence m m is negative. Since the derivative is the limit as x 2 x_2 approaches x 1 x_1 , it follows that the derivative must be positive on an interval where f f is increasing, and negative when f f is decreasing.

But what if we take an interval where f f increases in one area and decreases in another; for example the interval ( -2 , 2 ) (-2,2) on g ( x ) g(x)? Then the slope of the tangent line must go from positive to negative (or vice versa), so as a point ( x , f ( x ) ) (x,f(x)) slides from left to right (i.e. as x x increases along the interval), it passes through a point on f f where the slope of the tangent line is equal to 0. That is, there exists a point on f f such that f ′ ( x ) = 0 f'(x)=0 . Visually, these look like peaks or valleys in the graph of the function, points x x for which f ( x ) f(x) attains either the highest value (maximum) or lowest value (minimum) on some interval containing x x . We call such points extreme values or extrema of f f . It turns out that, for any closed interval [ a , b ] [a,b] , extreme values always exist:

Theorem (Extreme value theorem). If y = f ( x ) y=f(x) is a function that is defined and continuous on a closed interval [ a , b ] [a,b] , then this function attains both a maximum and a minimum at some points in the interval; that is, there exist points c c and d d in [ a , b ] [a,b] such that f ( c ) ≤ f ( x ) ≤ f ( d ) f(c) \leq f(x) \leq f(d) for all x x in [ a , b ] [a,b] .
